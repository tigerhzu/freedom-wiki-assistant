# 視覺編輯指南

Wiki Studio 的「視覺編輯」沿用內部 Future／hybrid 模式名稱。你可以直接點選文章、輸入與調整圖片，最後由 Wiki.js 原生 SAVE 儲存；既有 Classic／Future 名稱仍會出現在部分設定值與程式碼中。

## 開始編輯

1. 登入已設定的 Wiki.js，開啟 `/e/…` 編輯頁。
2. 在原生 SAVE／PAGE／CLOSE 附近切換「原始碼」或「視覺編輯」。
3. 點選文章輸入、貼上文字，或對圖片按右鍵調整樣式。
4. 完成後按原生 SAVE，並確認 Wiki.js 顯示的儲存結果。

原始碼側的 Markdown、Classic 預覽與 Future 視覺工作區透過同一份文件模型同步。一般視覺輸入先維持畫面反應，停止輸入約 700 ms 後批次轉為 Markdown。按 SAVE 前會完成待同步內容；若同步無法完成，會顯示訊息並保留內容，不直接交給 Wiki.js 儲存。

## 文字與段落

反白文字後可使用可見格式工具列或右鍵選單。提供粗體、斜體、底線、刪除線、標記、行內程式碼、文字大小與色彩，以及段落對齊、引用、縮排和資訊框。部分格式使用 HTML 儲存在 Markdown 中，顯示方式取決於 Wiki.js renderer 與網站的 HTML 清理設定。

| 快捷鍵 | 行為 |
| --- | --- |
| `Ctrl / ⌘ + Shift + K` | 開啟工作台、搜尋工具 |
| `Alt + F10` | 從文章移至格式工具列 |
| `Ctrl / ⌘ + B / I / U` | 粗體／斜體／底線 |
| `Escape` | 優先關閉面板或對話框，工具列則回到文章 |

## 圖片

貼上或拖入 PNG、JPG、JPEG、WEBP、GIF 會走 Wiki.js Assets 上傳流程。可依目前文章路徑、父資料夾或手動選取目標；目前單檔上限為 5 MB。圖片以資產 URL 插回文件，不會以 Base64 當作正常儲存格式。

在圖片上按右鍵，可設定寬度、原始尺寸、自訂寬高、對齊、圓角、框線，或還原 Markdown 圖片。等待所有上傳完成後再儲存。管理既有圖片時，可從工作台進入圖片資料庫；重新命名與刪除會操作 Wiki.js 的真實資產。

## 切換、儲存與限制

編輯模式切換和原生 Close 流程會先處理待同步的視覺內容，Wiki.js 仍決定是否儲存、提示或離開。頁面最終有沒有保存成功，以 Wiki.js 的原生結果為準。

如果遇到同步衝突、尚未完成同步或來源與畫面不同，先保留必要內容，不要直接重新整理。可回到原始碼檢查 Markdown，並依 [疑難排解](TROUBLESHOOTING.md) 處理。工作副本在目前頁面記憶體中，不能將設定備份當成文章草稿備份。

原生 Wiki.js 預覽是正式顯示依據；本機互動範例使用簡化 renderer，只供介面與同步測試。同步細節見 [架構文件](ARCHITECTURE.md)。
