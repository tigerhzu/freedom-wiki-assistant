# 版本紀錄

## 0.3.4 · Wiki Studio

- 工作台、客戶目錄、模板、圖片資料庫、設定頁與導覽採用一致的 Wiki Studio 介面。
- 保留可拖曳 Pet 與位置記憶，增加工作台搜尋、Pet 顯示切換和鍵盤入口。
- 視覺格式工具列與文字／圖片右鍵操作，搭配文件模型、序列投影與儲存前同步。
- 圖片編輯回歸修正涵蓋相鄰圖片、HTML 屬性保留、圖片上傳競態、失敗還原與貼上歷史。
- Ornith／Azure OpenAI 採單一 Provider 設定，排版結果提供差異與確認套用流程。
- 公開文件重新整理為產品首頁、架構、開發、安裝與發行指南；品牌 SVG 與跨專案導覽納入原始碼。
- 公開安裝包以示範網站為預設，附離線網域設定腳本。

## 0.3.3

既有版本延續 0.3 系列編輯功能。原 README 未提供獨立的 0.3.3 明細；本頁不推測其個別變更，精確差異請以 Git 歷史與既有 Release 紀錄為準。

## 0.3.2

- 修正切換 Wiki.js 頁面時，側欄自訂色短暫閃回原始顏色的問題。

## 0.3.1

- 改善視覺編輯輸入延遲、焦點跳動與背景同步造成的捲動干擾。
- 視覺輸入維持前景操作，閒置後批次同步 Markdown。

## 0.3.0

- 導入 Classic／Future 模式切換與 Wiki.js 原生 SAVE／PAGE／CLOSE 整合。
- 客戶目錄加入排序、重新命名、分類、匯入／匯出與保存目前頁面。
- 模板支援搜尋、分類、預覽、插入、編輯、複製與資料搬移。
- 設定頁涵蓋側欄外觀、圖片規則、AI Provider 與完整／不含 Key 備份。
