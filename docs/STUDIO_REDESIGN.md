# Wiki Studio · 柔和介面與 Pet

本次將 Freedom Wiki Assistant 的操作層重新整理成 Wiki Studio，採用接近 iOS 的柔和藍色、冷灰白背景、半透明浮層與圓潤控制項。客戶浮窗移除大型英文標頭與常駐管理工具列，將空間留給搜尋和清單。Pet 保留為可拖曳的動畫角色，點擊直接開啟客戶懸浮視窗；其他功能可由頂部工作台與快捷鍵開啟。

## 核心功能與保留邊界

| 功能 | 新介面 | 保留的行為 |
| --- | --- | --- |
| Markdown / 視覺編輯 | 原始碼／視覺編輯切換、白紙工作區 | 內部 classic / hybrid / raw 設定相容；共用 WikiDocumentSync；Markdown 投影與 Wiki.js 原生儲存 |
| 文字格式 | 可見格式工具列、更多格式、右鍵選單 | 粗體、斜體、底線、標記、色彩、大小、對齊、引用與資訊框；維持局部來源修改 |
| 圖片上傳與樣式 | 拖入／貼上、右鍵調整 | Wiki.js Assets 流程、資料夾規則、去重、取消、大小、對齊、圓角與邊框 |
| 圖片管理 | 縮圖圖庫、檔名原處編輯 | 遞迴子資料夾、選取、個別與批次刪除；刪除確認可取消並留在原圖庫 |
| Pet、客戶與常用頁面 | 動畫 Pet、跟隨 Pet 的客戶浮窗、跨名稱／路徑／分支搜尋 | 拖曳位置記憶、分類、排序、重新命名、分支、匯入／匯出、收藏目前頁面 |
| 模板 | 搜尋與分類、主要操作與更多管理分開 | 插入預覽、取代全文確認、變數、編輯、複製、刪除、拖曳、備份 |
| 頁面拓譜 | 工作台入口與一致的關聯圖配色 | 現有階層、連結探索、縮放與展開 |
| AI 排版 | 啟動說明、明確開始、結果檢閱 | Ornith / Azure 單一服務、選取範圍、分塊、差異與警告、確認套用 |
| 設定與導覽 | 五個分區、儲存狀態、三步驟互動導覽 | Provider 鎖定、API Key 本機儲存、完整備份與不含 Key 的搬移版本 |

編輯器的 IME、游標、歷史、同步世代、延遲投影與原生 Save/Close 保護機制沿用目前工作區實作。工具列放在文章容器外，避免將介面內容序列化為 Markdown。既有側欄自訂設定保持相容，首次安裝的側欄預設為柔和藍。

## 設計系統

主色 `#287dea`、冷灰白背景 `#f2f5fa`、白色紙面與深灰藍文字 `#202c3e`。工具面板採用 22px 左右圓角、低對比邊界、柔和陰影與半透明背景，並提供足夠不透明度確保文字易讀；控制項使用約 12px 圓角。介面统一採用系統無襯線字，不再使用大型英文襯線標頭與等寬字標籤。文章與原始碼仍保留各自的閱讀語意。

客戶浮窗的標題、新增、更多與關閉放在同一列，下方為搜尋欄。收藏目前頁面、新資料夾、匯入及匯出收進更多選單；客戶與分支每列亦使用一個管理選單。選單支援方向鍵、Home／End、Escape、點擊外部關閉與焦點交還，開啟表單前會先關閉選單。

`src/styles/studio.css` 負責 Shadow DOM 中的共用視覺樣式；`workspace-panels.css` 負責工作台與目錄；`pet.css` 負責角色顯示；`editor-actions.css` 只處理原生標頭內的擴充功能按鈕；`hybrid-preview.css` 處理編輯工作區；設定頁有獨立 `settings.css`。

## Pet 操作

- 點擊 Pet 開啟或關閉客戶浮窗，拖曳不會誤觸開窗；位置會儲存。
- 「設定 → 外觀與 Pet」或「工作台 → 隱藏 Pet／顯示 Pet」可切換顯示。舊設定與備份預設保留顯示。
- 隱藏 Pet 後，頂部工作台與 `Ctrl / ⌘ + Shift + K` 仍可開啟客戶目錄或重新顯示 Pet。
- 浮窗跟隨 Pet 並限制於視窗邊界內，避開原站儲存列。Pet 在隱藏、背景分頁或系統減少動態效果時停止動畫。
- Pet 顯示與拖曳不會重建文章編輯器；設定頁會同步其他 Wiki 頁面的 Pet 狀態與位置。

## 鍵盤操作

- `Ctrl / ⌘ + Shift + K`：開啟工作台，直接輸入搜尋，方向鍵選工具、Enter 開啟。
- `Alt + F10`：從視覺文章移至格式工具列；方向鍵切換控制。
- `Ctrl / ⌘ + B / I / U`：格式化視覺文章中的選取文字。
- `Escape`：先關閉目前面板或對話框，工具列則回到文章；沒有其他介面時保留切回原始碼的行為。
- 對話框支援前後 Tab 循環，關閉後將焦點交還入口。對話框開啟時，文章快捷鍵不會修改背景文件。

## 驗證與使用

`npm run typecheck`、`npm run lint`、`npm test`、`npm run build` 提供正式檢查與建置。測試涵蓋 Pet 點擊、拖曳、隱藏與恢復、窄視窗邊界、設定同步、舊備份相容，以及格式工具列、對話框焦點、圖片刪除取消和工作台搜尋。

`npm run preview:studio` 在 `http://127.0.0.1:4187/` 啟動互動範例；使用實際介面元件與獨立 sessionStorage 資料，Wiki origin 固定在本機。此範例的簡化 Markdown renderer 不取代正式 Wiki.js renderer；圖片上傳和 AI 服務也不在範例中執行。

正式使用時，在瀏覽器擴充功能管理頁重新載入 `dist/` 並重新整理 Wiki。公司環境的登入、Assets 與 AI 連線仍需在該環境確認。
