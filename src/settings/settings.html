AI 排版（Azure OpenAI）

沿用 HaloPSA 擴充套件的 Azure OpenAI 設定格式；Endpoint／Deployment／API Key 只儲存在本機瀏覽器 （chrome.storage.local），不會寫死在程式碼或打包進擴充套件中。AI 排版只會整理目前頁面的 Markdown／HTML，並在你確認 Diff 後才寫入編輯器，不會自動儲存到 Wiki。

Prompt Cache：Azure 對 GPT-4o 以後的模型會自動快取提示前綴（不需設定、也無法關閉），排版規則因此固定放在 System Prompt、文章內容一律放最後。實際命中量會記錄在頁面 Console 的 [FWA] AI 排版完成 那一行；若顯示「cached input 未回報」，代表這個 Deployment 的模型或 API Version 沒有回傳 prompt_tokens_details.cached_tokens。

文章太長時會自動切段循序送出，避免單次回應被 max_tokens 截斷；切段時每段看不到其他段落， 跨章節的標題層級請自行確認。若只想整理其中一段，先在編輯器選取該範圍再按 AI 排版。
